# PinSnap

**截完就能标注的 macOS 截图工具。**

框选、标注、复制、钉在屏幕上——全程都在截图画面里完成，不会再弹一个预览窗口让你确认一次。

## 功能

- **三种截图方式**：区域、全屏、窗口
- **框选即编辑**：松开鼠标直接进入标注状态；要多截一点或缩小范围时，拖选区四边或四角即可调整
- **六种标注**：矩形、箭头、编号、画笔、文字、马赛克
- **复制 / 保存 / Pin**：一键进剪贴板、存成 PNG，或者钉在屏幕上对照查看
- **原样清晰**：按屏幕原生像素抓取，Retina 上也是 1:1，不糊不缩水
- **Pin 可缩放**：滚轮或触控板捏合，以光标为中心放大缩小

## 安装

1. 到 [Releases](https://github.com/zrqg-znb/pin-snap/releases/latest) 下载 `PinSnap-x.y.z.dmg`
2. 打开 dmg，把 `PinSnap.app` 拖进 `Applications`
3. 首次启动会提示授权，按引导到「系统设置 → 隐私与安全性 → 屏幕录制」允许 PinSnap

## 使用

### 截图

打开主窗口点按钮，或者点菜单栏的取景框图标，也可以直接按键：

| 方式 | 说明 |
| --- | --- |
| 区域截图 | `⌘⇧2`，拖出想要的范围 |
| 全屏截图 | 截取鼠标所在的那块屏幕 |
| 窗口截图 | 点选一个窗口单独截取 |

### 标注

拖完选区就进入编辑，工具栏出现在选区下方。想修改范围时，直接拖选区的蓝色边框或八个把手（四边、四角）即可：

> 矩形 · 箭头 · 编号 · 画笔 · 文字 · 马赛克 ｜ 撤销 · 重做 ｜ 取消 · 复制 · 保存 · Pin

编号会自动递增，写步骤说明很方便；马赛克拖多大糊多大。

### 收尾

| 想做什么 | 怎么做 |
| --- | --- |
| 复制到剪贴板 | `Return` |
| 保存成 PNG | `⌘S` |
| 钉在屏幕上 | 点工具栏的图钉 |
| 不截了 | `Esc` |

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `⌘⇧2` | 区域截图（全局生效，其他应用在前台也能用） |
| `Return` | 复制 |
| `⌘S` | 保存 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `Esc` | 取消 |

## Pin 窗口

截图钉在屏幕上之后：

- 默认按原始尺寸显示，不会自动放大
- 拖四边或四角改大小，按住 `Shift` 自由拉伸
- 滚轮或触控板捏合缩放，光标指着的地方保持不动
- 双击回到原始大小，`Esc` 关闭
- 右键可复制、保存、关闭

对着参考图写东西、或者比对两个版本时很好用。

## 系统要求

- macOS 14 或更高
- Apple Silicon（M 系列芯片）

## 常见问题

**首次打开提示「无法验证开发者」**

这个构建没有做 Apple 公证。右键点按图标选「打开」，或者执行：

```bash
xattr -dr com.apple.quarantine /Applications/PinSnap.app
```

**已经授权屏幕录制，截图时还是提示「屏幕截图被系统拒绝」**

说明系统没把权限给到当前运行的这个副本。对话框里会列出实际路径，确认它就是「屏幕录制」里勾选的那个；如果不是，到「系统设置 → 隐私与安全性 → 屏幕录制」用 `−` 移除再点 `+` 重新添加 `/Applications/PinSnap.app`，然后完全退出 PinSnap 重新打开。

**两块屏幕怎么算**

以鼠标所在的那块屏幕为准，各自按自己的缩放比抓取原生像素，不会把 Retina 屏截成一半分辨率。

